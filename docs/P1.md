# P1 — Stabilité de l'extension 1.2.1

## Objectif

Corriger ce qui cassait ou exposait des données, sans changer le parcours Haiku ni l'apparence.

## Fichiers

Modifiés : `manifest.json`, `background.js`, `content.js`, `options.html`, `options.js`.
Ajoutés : `lib/core.js`, `tests/core.test.js`, `tests/demo/formulaire.html`, `package.json`, ces notes.

## Corrections

- Sonnet 5.5 et Opus 5.5 n'utilisent plus `tool_choice: tool`, refusé par l'API. Sonnet envoie `thinking: between_tools` et un outil `strict`. Opus envoie un outil `strict` et `tool_choice: auto`. Haiku conserve l'appel de la 1.2.0 : version `2023-06-01`, outil forcé, 1500 jetons, `maxItems: 2`.
- Le schéma strict retire `maxItems`, non accepté par l'API stricte. Le plafond de deux couleurs est appliqué après la réponse.
- Une réponse est refusée si le titre ou la description manque. Un état hors liste, une couleur hors liste ou un prix invalide est retiré plutôt qu'écrit dans le formulaire.
- Cinq photos maximum, base64 JPEG, précisions et signature bornées.
- `generate`, `fetchImage` et `getPrefs` ne répondent que depuis `https://www.vinted.fr`. `testKey` ne répond que depuis la page de l'extension.
- La récupération d'image n'envoie pas les cookies, ignore le referrer, et rejette une redirection hors Vinted.
- Les photos distantes doivent être sur `vinted.net` ou `vinted.fr`. Les miniatures locales (`blob:` et `data:`) restent prioritaires.
- Le panneau est en shadow DOM fermé : un script de la page ne peut plus cliquer sur Générer.
- Hors page de vente, la surveillance passe de 800 ms à 2 s. Sur la page de vente, elle reste à 800 ms, donc la génération automatique garde son délai.
- Les erreurs API affichées sont tronquées à 180 caractères. La clé n'est pas recopiée dans le message.

## Vérification

`node --test tests/core.test.js` : 10 tests, 10 réussites. Ils couvrent le prix, les libellés, les hôtes, les bornes, le nettoyage d'annonce, les réglages, la forme des appels Haiku / Sonnet / Opus et l'origine des messages.

Aucun appel réseau vers Anthropic ou Vinted n'a été fait : il n'y a pas de clé dans le dépôt. Le formulaire de démonstration vérifie les sélecteurs et les libellés, pas le clic réel dans Chrome.

Pour prendre la 1.2.1 : chrome://extensions, recharger l'extension, puis F5 sur l'onglet Vinted. Chrome peut redemander l'accès aux images `vinted.fr`.

## Risques restants

- Les sélecteurs de menus peuvent manquer la prochaine version de la page Vinted. Le texte reste alors dans le panneau, à copier.
- Si le CDN d'une photo n'est ni `vinted.net` ni `vinted.fr`, l'édition d'une annonce existante ne la lira pas. Il faut retirer puis remettre la photo.
- La clé Claude est toujours sur l'ordinateur. Le quota et OpenAI arrivent en P2.
- Opus peut encore répondre sans appeler l'outil. Le message demandé est alors « annonce inexploitable », et l'utilisateur réessaie.
- Le remplissage des menus reste une aide sur la page déjà ouverte. Ce n'est pas une autorisation de publier, négocier ou écrire à la place du vendeur.
- Les autres domaines Vinted (`.be`, `.es`, etc.) ne sont pas couverts.
