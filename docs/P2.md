# P2 — API Laravel, OpenAI côté serveur

Objectif : analyser 1 à 5 photos sans demander de clé API au client. La clé OpenAI reste sur le serveur. L'extension 1.2.1 continue d'appeler Claude tant qu'aucune session serveur n'est enregistrée.

Rien n'est déployé. Aucune clé réelle n'est dans le dépôt.

## Architecture

```
Extension Chrome 1.3.1
  content.js  →  message generate (photos JPEG, précisions)
  background  →  si backendToken : POST /api/v1/listings/analyze
              →  sinon, si clé Claude : parcours Haiku / Sonnet / Opus inchangé
              →  sinon : erreur, aucune clé

Laravel 12  (backend/)
  Sanctum    jeton porteur, expiration configurable, pas de cookie SPA
  MySQL      base documentée pour l'application
  SQLite     mémoire, uniquement pour PHPUnit

  AuthController          register, login, logout, me
  ListingController       une analyse
  AnalyzeListing          plafond, réserve, appel, validation, règlement
  OpenAIListingClient     Chat Completions, json_schema strict
  ListingValidator        contrat de sortie, jamais la confiance au modèle
  CreditLedger            quota, une analyse à la fois, réserve de coût, plafonds
```

Le client mobile futur consomme les mêmes routes `/api/v1`. L'authentification est un jeton porteur, donc elle ne dépend pas des cookies du navigateur.

`plans.stripe_price_id` est une colonne nullable, inutilisée. Le plan `free` est créé par la migration. Un plan payant futur lira `monthly_credits` dans la table ; le plan gratuit lit `CREDITS_MONTHLY` pour pouvoir changer le quota sans modifier le code. Stripe, les abonnements et un tableau de bord admin ne sont pas développés.

## Contrat d'analyse

`POST /api/v1/listings/analyze`, jeton requis.

Entrée : `images` (1 à 5 JPEG réels, 32 à 2048 pixels, 1,125 Mo décodés au plus), `precisions` (300), `style` (`court`, `normal`, `detaille`), `hashtags`, `signature` (300).

Sortie validée : `titre`, `description`, `categorie`, `sous_categorie`, `marque`, `taille`, `etat`, `couleurs` (2 maximum, vocabulaire de l'extension), `matiere`, `prix_suggere`, `a_verifier`. Un titre ou une description vide est rejeté. Les attributs inconnus sont retirés. Le serveur n'écrit rien chez Vinted.

Les photos ne sont pas enregistrées. Le journal ne contient que l'identifiant utilisateur, le statut, le modèle, le coût estimé, la durée et le code d'erreur.

## Crédits, fréquence, coût

1. Refus immédiat si `OPENAI_API_KEY` est vide (503, aucun appel).
2. Une transaction verrouille d'abord la ligne `credit_guards`, puis l'utilisateur. Elle expire les réservations de plus de 180 secondes, refuse une seconde analyse déjà en cours, refuse le dépassement du quota, puis refuse si le coût du jour plus une réserve de 0,02 USD atteint le plafond.
3. La réserve est enregistrée avant l'appel. Le verrou est relâché avant d'attendre OpenAI.
4. Succès : le crédit reste débité et la réserve est remplacée par le coût mesuré.
5. Échec réseau ou HTTP : le crédit revient à 0, la réserve de coût reste pour couvrir un appel peut-être facturé. Une sortie illisible garde le coût mesuré.
6. Limite de fréquence `listings` par utilisateur (6 par minute par défaut) et 8 tentatives par minute sur l'inscription et la connexion.

Le modèle, le détail d'image, l'effort de raisonnement, les prix au million de jetons et les plafonds viennent de l'environnement. Le modèle par défaut est `gpt-5.6-luna`.

## Migration de l'extension

| Situation | Moteur |
| --- | --- |
| Jeton de session présent | Laravel uniquement. Un échec du serveur ne bascule pas vers Claude. |
| Pas de jeton, clé Claude présente | Parcours 1.2.1 inchangé. |
| Ni jeton ni clé | Message demandant une clé, comme avant. |

Le jeton reste dans `chrome.storage.local`. Il n'est pas envoyé au script de contenu. La clé Claude n'est pas envoyée à Laravel. Le mot de passe du compte n'est pas stocké.

Adresses acceptées, et aucune autre : `http://127.0.0.1:8000` et `http://localhost:8000`. `API_OFFICIELLE` dans `lib/core.js` est vide. Le jour où le domaine de production est le nôtre, cette constante et la permission d'hôte correspondante reçoivent la même origine HTTPS, caractère pour caractère. La permission optionnelle `https://*/*` a été retirée. Un jeton présent avec une adresse refusée ne bascule pas vers Claude : l'appel est rejeté avant l'envoi. La règle de prix locale s'applique encore après la réponse du serveur.

Non versionnés : `backend/.env`, `backend/vendor`, les bases SQLite locales.

## Lancer en local

PHP 8.4, Composer, et une base MySQL `vinted_ia`. Copier `backend/.env.example` vers `backend/.env`, renseigner `APP_KEY` et `OPENAI_API_KEY` sur la machine, puis `php artisan migrate` et `php artisan serve`. L'extension pointe par défaut vers `http://127.0.0.1:8000`. Créer le compte avec `POST /api/v1/auth/register` ou depuis une future inscription ; la page de réglages connecte un compte déjà créé.

Les tests PHPUnit n'utilisent pas MySQL : `phpunit.xml` force SQLite en mémoire.

## Tests

- `npm test` : 13 tests. Règles de prix, schémas Claude, origines de messages, choix du moteur, URL strictement autorisée, corps de requête sans clé Claude.
- `php artisan test` : 26 tests, 124 assertions. Santé sans fuite de clé, auth, expiration du jeton, JPEG, 1 à 5 photos, débit d'un crédit, quota, sortie invalide, plafond, clé absente, fréquence, délai d'expiration, erreurs 400 et 429 sans écho du corps amont, réservation déjà en cours. Le fournisseur est simulé.
- Avec `VINTED_IA_MYSQL_PORT` : 8 processus réservent en parallèle. Un seul crédit est débité.

## Validation du 11 novembre 2026

`gpt-5.6-luna` accepte, d'après la documentation OpenAI, les images, Chat Completions et les sorties structurées. Le schéma envoyé est un objet strict, tous les champs sont requis, et il n'utilise pas `minLength`, `maxLength`, `maxItems`, `format` ni `pattern`. Les prix configurés reprennent le tarif publié : 0,20 USD le million de jetons d'entrée, 1,20 USD le million en sortie.

`php artisan listings:probe` a répondu `schema_strict=ok`, `openai_key=absent`, `model_access=not_run`. Aucune clé n'est présente dans `backend/.env` ni dans l'environnement utilisateur ou machine. Le compte API n'a donc pas été appelé. Aucun temps de réponse, aucun jeton et aucun coût réel n'ont été mesurés. La commande n'affiche pas la clé.

Les six migrations se sont exécutées sur MariaDB 10.4.32, instance privée sur `127.0.0.1:33060`, en 728 ms. Le mot de passe root de l'instance XAMPP déjà installée n'est pas celui indiqué par phpMyAdmin, et Docker Desktop ne répondait pas. Le plan du total journalier utilise `usage_events_created_at_index` (range). Le total mensuel d'un utilisateur utilise `usage_events_user_id_created_at_index` (ref). Huit processus parallèles ont produit une seule réservation et un seul crédit.

Le parcours extension a été rejoué avec `tests/extension-chain.cjs` contre Laravel, le fournisseur étant un simulateur local. Une photo, puis cinq photos, ont renvoyé le titre, la taille M, la matière coton, une marque vide et l'état. La règle de prix a transformé 18,2 en 16. La déconnexion a rendu le jeton inutilisable (401). Le simulateur a reçu exactement deux appels. Le journal Laravel ne contient ni la clé d'essai ni les photos. Le serveur de développement Windows ne peut pas forker (`forking is not supported`), donc ce parcours HTTP était sérialisé. La preuve de concurrence reste le test des huit processus.

L'extension n'a pas été chargée dans Chrome, et la page Vinted réelle n'a pas été rouverte. Sans jeton, `choisirMoteur` reste sur Claude. Ce chemin n'a pas été rappelé.

## Limites

- Le compte OpenAI n'a pas été joint. Le coût réel d'une annonce reste inconnu tant que `OPENAI_API_KEY` n'est pas posée dans `backend/.env`, hors du dépôt. `php artisan listings:probe` fera alors la mesure sans afficher la clé.
- `API_OFFICIELLE` est vide. Aucun domaine de production n'est encore autorisé à recevoir le jeton.
- Les migrations ont réussi sur MariaDB 10.4, pas sur un serveur MySQL 8 séparé.
- Chrome et le DOM Vinted réel ne font pas partie de cette validation. Claude reste en place.
- Pas de Stripe, pas d'admin, pas de file d'attente : l'analyse répond dans la requête HTTP, dans la limite de `OPENAI_TIMEOUT`.
- Les autres pays Vinted ne sont pas retestés. Le remplissage du formulaire n'a pas été modifié, hormis l'affichage de la sous-catégorie.
- Un vendeur particulier ne peut toujours pas publier, envoyer un message ou relancer une annonce par automatisation.
